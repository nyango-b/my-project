# Personal Portfolio Website

This is a multi-page personal portfolio website built using *HTML, CSS, and JavaScript*. It showcases my skills, projects, and allows users to contact me or fill out a survey.

## Features
- Homepage with a greeting message
- About Me section with a 2-column layout
- Portfolio/Projects page with a 3-column layout
- Contact form with validation
- Survey page using radio buttons, checkboxes, and textarea
- Dark/Light mode toggle
- Responsive design for desktop and mobile
- JavaScript DOM manipulation and event listeners

## Tools Used
- HTML5 & Semantic Elements
- CSS3 (inline, internal, and external stylesheets)
- JavaScript
- Git & GitHub

## Challenges Faced
- Getting dark mode to work across multiple pages
- Styling for responsiveness
- Form validation using regex
