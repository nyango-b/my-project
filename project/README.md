Description:
This project is a personal portfolio website created using HTML, CSS, and JavaScript. It showcases my personal information, projects, contact form, and a user survey. The website supports dark mode and is fully responsive for mobile and desktop screens.

---

Project Structure:
.
├── index.html           # Home page  
├── about.html           # About Me page  
├── portfolio.html       # Projects/Portfolio page  
├── contact.html         # Contact form page  
├── survey.html          # Survey form page  
├── css/
│   └── style.css        # CSS styling for all pages  
├── js/
│   └── script.js        # JavaScript functionality (toggle dark mode, validate forms, etc.)  
└── images/              # Optional folder for profile or project images  

---

Features:
- Multi-page structure with navigation links on each page  
- Responsive design using CSS Flexbox and media queries  
- Dark/Light mode toggle with preference saved across pages  
- Contact form with email validation  
- Project section with dynamic show/hide details using JavaScript  
- Survey form with various input types  

---

How to Run:
1. Extract the zip file to a folder on your computer.  
2. Open index.html in a web browser.  
3. Use the navigation links to explore the other pages.  

---

Tools Used:
- HTML5  
- CSS3  
- JavaScript (Vanilla)
